# Social Network Frontend

Простой веб-интерфейс для социальной сети, построенный на HTML, CSS и JavaScript.

## 🚀 Возможности

- **Аутентификация**: Вход и регистрация пользователей
- **Дашборд**: Главная страница с лентой новостей
- **Посты**: Создание, просмотр и удаление постов
- **Друзья**: Поиск пользователей и управление друзьями
- **Сообщества**: Создание и участие в сообществах
- **Адаптивный дизайн**: Работает на всех устройствах

## 📁 Структура проекта

```
frontend/
├── index.html          # Главная страница с авторизацией
├── dashboard.html      # Дашборд пользователя
├── css/
│   └── style.css       # Стили приложения
├── js/
│   ├── api.js          # API клиент для работы с backend
│   ├── auth.js         # Логика авторизации
│   └── dashboard.js    # Логика дашборда
└── images/             # Изображения (пока пустая)
```

## 🛠️ Установка и запуск

### Предварительные требования

1. Backend приложение должно быть запущено на `http://localhost:8080`
2. Современный веб-браузер с поддержкой ES6+

### Запуск

1. Откройте файл `frontend/index.html` в браузере
2. Откройте `http://localhost:8000` в браузере

## 📱 Использование

### Регистрация и вход

1. Откройте главную страницу
2. Нажмите "Регистрация"
3. Заполните форму регистрации
4. После регистрации войдите в систему

### Основные функции

#### Создание постов
- На дашборде введите текст в поле "Создать пост"
- Нажмите "Опубликовать"

#### Управление друзьями
- Перейдите в раздел "Друзья"
- Нажмите "Найти друзей" для поиска пользователей
- Отправляйте запросы в друзья

#### Сообщества
- Перейдите в раздел "Сообщества"
- Создайте новое сообщество или присоединитесь к существующему

## 🔧 API интеграция

Frontend использует REST API backend приложения:

- **Аутентификация**: `/auth/login`, `/auth/register`
- **Пользователи**: `/users/me`, `/users/search`
- **Посты**: `/posts/create`, `/posts/my-posts`, `/posts/all`
- **Друзья**: `/friendships/request/{id}`, `/friendships/my-friends`
- **Сообщества**: `/community/create`, `/community/my-communities`
